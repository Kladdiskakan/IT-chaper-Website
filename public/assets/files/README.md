# Produktkatalog

Placera er produktkatalog här som `produktkatalog.pdf`

Filen kommer att vara tillgänglig på:
`/assets/files/produktkatalog.pdf`

## Instruktioner:
1. Byt namn på er PDF-fil till `produktkatalog.pdf`
2. Placera filen i denna mapp
3. Uppdatera filstorleken i `company-info-card.tsx` om nödvändigt

## Tekniska krav:
- Format: PDF
- Rekommenderad filstorlek: Max 10MB
- Namn: `produktkatalog.pdf`
